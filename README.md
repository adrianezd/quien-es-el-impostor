# ¿Quién es el Impostor?

Juego de fiesta gratuito para grupos, pensado para jugarse en **un solo móvil compartido** que se va pasando entre los jugadores. Sin cuentas, sin descargas, sin necesidad de red entre dispositivos.

🔗 **Jugar ahora:** https://adrianezd.github.io/quien-es-el-impostor/

> Nota: tras el primer despliegue en GitHub Pages, la página puede tardar uno o dos minutos en estar disponible.

## Cómo jugar

1. Elige el número de jugadores (3-15), el número de impostores y una categoría de palabras.
2. Pulsa **Crear sala**. El móvil se pasa de jugador en jugador; cada uno mantiene pulsado el botón para ver su rol en privado (la palabra secreta, o si es el impostor) y confirma antes de pasar al siguiente.
3. Los jugadores que conocen la palabra dan pistas sutiles sin decirla; el impostor intenta disimular que no la conoce.
4. Se debate (con un cronómetro opcional) y, cuando el grupo esté listo, se pulsa **Revelar impostor(es)** para ver quién era el impostor y cuál era la palabra secreta.
5. Se puede jugar otra ronda con los mismos ajustes o volver a la configuración inicial.

Cada ronda genera una palabra y unos roles nuevos completamente en memoria: nada se guarda, así que recargar la página borra por completo la ronda en curso.

## Aviso

Este es un juego de fiesta **original**, basado en el concepto genérico de "deducción social con una palabra secreta", que existe en muchas variantes desde hace años. No está afiliado ni asociado a ninguna marca, producto o juego comercial concreto.

## Stack técnico

Sitio estático sin dependencias: HTML, CSS y JavaScript vanilla. Sin build, sin frameworks, servido directamente por GitHub Pages.
